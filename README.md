# Personal Portfolio Website

A responsive personal portfolio with project cards, skills, and a contact form backed by an Express API.

## Requirements
Node.js 18+.

## Run
```bash
npm install
npm start
```
Open http://localhost:3000. The contact API validates fields and returns a success response. This starter does not send email or persist messages yet; connect an email provider or database before describing those features as complete.

## Customize
Edit `public/index.html` with your name, skills, projects, and contact details. Keep secrets out of source code.
